# 06 — Simulink model

The Simulink model `lqr/tipy_triple_pendulum.slx` is generated
programmatically by `lqr/build_simulink.m`. Running the function
deletes any existing `.slx` and rebuilds it deterministically.

## Structure

```
Plant state -> Sum_x(+) -> Gain -K -> Sat -> Plant input
x_e --------> Sum_x(-)
Plant state -----------------------> Demux / scopes / workspace
```

`Plant` is `lqr/plant_sfun.m`, a Level-2 MATLAB S-function that wraps
`dynamics`. It accepts the saturated
force and outputs the 8-element state vector.

`x_e` is the upright state `zeros(8,1)`.  The sum forms `dx = x - x_e`.  The
gain block encodes `u = -K dx`, with K generated by `controller.m`. The
saturation block enforces
`|u| <= u_max`.

## Solver

Fixed-step `ode4` at `Ts = 0.005 s`.  `StopTime = 10 s`.

## Initial state

The Plant block is initialized to `x0 = [0.05; 0.10; 0.05; 0.05; 0; 0; 0; 0]`,
i.e. a 5 cm cart offset and 5-10 deg pole perturbation.  This is below the
linear-region threshold for the LQR weights above.

## Reproducibility

The script uses `new_system`, `add_block`, `add_line`, `set_param` and
`save_system`, so the model structure is reproducible from source.
